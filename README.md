## 作品について

佐渡にあった順徳院が壬辰の年に詠んだ百首に、隠岐の後鳥羽院が点を付け、定家（明静）が一首ごとに評語を加えたもの。定家の奥書は丁酉の年の10月で、明応・天正の書写奥書を伴う。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `zoku-gunsho-juntoku-in-hyakushu-tenhyo.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `zoku-gunsho-juntoku-in-hyakushu-tenhyo-0001`）は、本文を直しても変わりません。
